# 🚀 CIn-Events: Gestão Inteligente de Eventos

Bem-vindo à página oficial do **CIn-Events**. Este sistema foi projetado para centralizar e otimizar a organização de atividades acadêmicas no Centro de Informática da UFPE, unindo uma lógica robusta em C++ com uma interface moderna em React.

---

## 📑 Sobre o Projeto
O CIn-Events nasceu da necessidade de gerenciar o fluxo intenso de eventos do centro (Palestras, Workshops e Hackathons). O sistema não apenas registra atividades, mas aplica regras de negócio para garantir que a experiência do participante e do organizador seja fluida.

---

## 🛠️ Tecnologias e Arquitetura

O projeto se destaca pela separação de responsabilidades e pelo uso de conceitos avançados de EDOO:

### 💻 Backend (C++)
A inteligência do sistema reside em um núcleo C++ altamente modularizado:
- **Herança e Polimorfismo:** Classes base para `Evento` com especializações para `Palestra` (gestão de convidados) e `Hackathon` (gestão de equipes).
- **Encapsulamento:** Proteção total dos dados de inscrição e integridade do acervo.
- **STL (Standard Template Library):** Uso extensivo de containers para busca e ordenação eficiente.
- **Persistência:** (Em desenvolvimento/integrado) Conexão com SQLite para armazenamento seguro.

### 🌐 Frontend (React/JS)
Uma interface intuitiva que se comunica com o núcleo do sistema, permitindo que qualquer usuário interaja com as funcionalidades sem precisar lidar com o terminal.
